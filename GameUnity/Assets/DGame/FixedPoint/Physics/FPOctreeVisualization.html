一次查询如何完成

八叉树不负责替代形状相交算法。它的职责是先快速排除绝大多数空间，再把少量候选交给定点数精确检测。

01

初始化查询

清空复用列表，重置读取索引，将根节点加入待访问列表，并生成新的 castIndex。

02

处理本节点

按球、AABB、OBB、胶囊等集合扫描节点直接持有的碰撞器。

03

过滤候选

依次检查 enabled、trigger、dynamic、layerMask 和本次查询去重标记。

04

进入子节点

只有非空子树且查询体与子节点 AABB 相交时，才加入 openList。

05

精确相交

候选数量已经很少，再调用对应形状组合的定点数相交函数生成结果。

两个尺寸，各司其职

size 与 halfSize 不是简单的完整边长和半边长字段。前者记录逻辑层级尺寸，后者决定节点真实 AABB。

逻辑尺寸 size

根节点直接保存初始化参数；创建子节点时使用 node.size / 2。它还被 IsOutOfBound 用作逻辑边界。

AABB 半范围 halfSize

根节点通过二进制指数算法计算；子节点使用 node.halfSize / 2，并据此生成 Min 与 Max。

小碰撞器下沉

碰撞器 AABB 如果能被某一个子节点 AABB 完整容纳，就继续向该子节点搜索，直到叶节点。

跨边界对象留在父节点

物体只要跨越任一子节点分界，就保留在当前父节点。这样只存一份，不需要把同一个碰撞器复制到多个子节点。

本次逻辑审查

以下项目来自实际遍历状态和调用链检查。绿色项已在 FPOctree 内修复，黄色项需要结合生命周期或上层 API 单独处理。

查询状态串联

每次查询现在都会清空 openList 并重置 openListIndex，NonAlloc 提前退出不会污染下一次查询。

NonAlloc 数组越界

在节点内部写满结果数组时立即返回，不再等到下一轮 while 才检查容量。

角色查询空引用

角色集合和叶节点子数组都增加空值分支，空节点可以正常被遍历和跳过。

角色球体粗测反向

AABB 不相交时直接跳过；只有粗测相交才进入 Sphere 与 AACapsule 的精确检测。

碰撞器注销链路

OnDestroy 现在会经由 FPPhysicsContext 清理关联刚体、角色更新项、中央列表和所属节点，并同步递减祖先 colliderCount。

上层胶囊高度参数

FPPhysicsContext 现在会把实际 height 转发给 FPOctree，节点粗检测范围不再误用 radius。
